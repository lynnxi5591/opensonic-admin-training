# 欧贲官网后台 · 操作答疑 SKILL

给维护欧贲科技新版官网的同事用的 Claude SKILL。在后台遇到操作问题时直接问 Claude，它会像产品经理一样回答四件事：

- 在哪操作；
- 怎么操作；
- 要注意什么；
- 改完官网哪里会变。

每个回答都会附一张文字版菜单路径图和后台截图链接。

> 对应后台版本：`opensonic-website-admin-1028` · 当前 SKILL 版本见 [CHANGELOG](CHANGELOG.md)

---

## 一、怎么安装

1. 打开本仓库右侧的 **Releases**，下载最新的 `opensonic-admin-training.zip`，不用解压。
2. 在 Claude 的技能（Skills）设置里上传这个 zip。
3. 新开一个对话，直接提问就能用。

已经装过旧版本的，下载新版后重新上传，覆盖旧版本即可。

## 二、怎么用

直接用平时说话的方式问，比如：

| 想做的事 | 可以这样问 |
| --- | --- |
| 找功能在哪 | 新闻封面在哪换？ |
| 学会一个操作 | 怎么让一款产品出现在首页？ |
| 解决报错 | 产品的「在官网显示」打不开，怎么回事？ |
| 官网上看不到 | Banner 改完了，首页怎么没变？ |
| 检查要上架的内容 | （把产品资料贴进来）这些内容能直接填进后台吗？ |
| 发截图提问 | （发一张后台截图）这里该怎么填？ |

回答的格式是：

1. 一句话结论；
2. 菜单路径图和截图链接；
3. 操作步骤；
4. 注意事项；
5. 改完官网哪里会变。

### 回答的依据

- 所有回答只依据本仓库里的内容：`opensonic-admin-training/SKILL.md` 里的操作手册，和 `screenshots/` 里的后台截图。
- 不上网搜索，不给本仓库以外的链接。
- 手册里没写的，它会让你截图问项目负责人，不会自己猜。
- 截图里是示例数据，只用来看菜单位置和页面样子，不代表正式后台的实际内容。

### 它管不了的事

后台地址和账号、找回密码、SEO 设置、网址跳转、网站样式改动、服务器和存储问题，都要找项目负责人或开发。

## 四、维护（给维护人）

### 后台改版时

1. 在 Claude 的「OB 官网设计」项目里，把新的修改说明交给 Claude，让它更新 `SKILL.md` 对应模块的内容。如果菜单或页面样式变了，也让它重新截图，截图文件名保持不变。
2. 改版本号，两处要一致：`CHANGELOG.md` 加一行，`SKILL.md` 里「版本与更新」的版本号也改掉。同事那边的 Claude 靠这个判断有没有新版。
3. 提交到 main。
4. 在 Releases 新建版本，标签和版本号一致（比如 `v1.1.0`）。GitHub 会自动打包 zip 并附在这个版本下面。
5. 通知同事下载新版，重新上传安装。

### 版本号怎么定

- 只改文字、修正错误：第三位加 1，比如 v1.0.0 → v1.0.1。
- 后台加了功能或菜单：第二位加 1，比如 v1.0.0 → v1.1.0。

### 注意

- 本仓库是**公开**的。只放 SKILL、截图和说明，**不要放官网或后台的源码、`.env`、账号密码、客户数据**。
- 不要把 zip 文件提交到仓库里。zip 由 Releases 自动生成。
- 截图只能从后台设计稿或预览里截，不要用其他网站的图。
